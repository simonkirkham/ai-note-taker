Gutter Dot × Markdown — topics as a block overlay (Option B)

A topic is an attribute on any block — a ### header, a paragraph, or a bullet — not a special line type. Marking and ticking never change the note's markdown structure. Toggle the Markdown panel to see how it round-trips.

▶ Try this:  1) Hover any line → a gutter dot appears. Click it to make that line a topic (●), click again to tick it discussed (✓ — it strikes through in place, nothing moves).  2) Note “Agenda” & “Parking lot” are ### headers with no dot — headers that aren't topics.  3) Click the dot on the “rename the staging env” bullet — a non-header line becomes a topic. Topics ≠ headers, both ways.  4) Hit ⌁ Markdown to watch the encoding (~~done~~ + an invisible <!--topic-->).

What gets stored (markdown) 

      

        
Topic-ness is a block attribute, persisted with a tiny invisible marker; “discussed” reuses standard strikethrough. So the note stays clean, portable markdown — and a header is still a header.

        

          
### Budget <!--topic-->a header that's a topic (open)

          
### ~~Budget~~ <!--topic-->topic header, discussed

          
### Agendaa header that's not a topic

          
- vendor SLA… <!--topic-->a bullet that's a topic

    How it serves the 4 needs — and why it works with other markdown
    

      
Pre-recordWrite your agenda however you like — headers, bullets, plain lines — and dot the ones that are topics.

      
Mark-offOne click on the gutter dot ticks a topic discussed; it strikes through in place, nothing collapses or jumps.

      
StructureThe note keeps your real markdown structure (headers, bold, lists); topic-ness is just an overlay, and the pill tracks coverage.

      
Low frictionNo syntax to learn, no second pane, nothing reflows — same single surface you already type in.

      
Works w/ markdownBecause topic/done are attributes, not a block type, a ### header can be a topic OR just a header, and any paragraph/bullet can be a topic too — unlike a checkbox list, which can't also be a heading.
