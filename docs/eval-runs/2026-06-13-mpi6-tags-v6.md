# Eval run — MPI-6 `analysis@v6` tag-discipline pass

**What this run was for:** tags (the keywords the AI puts on each note so you can find related notes later) were the weakest part of every note — scoring 0.53–0.72 while everything else scored 0.85+. `analysis@v6` rewrites just the tagging instruction to ask for a small set of high-signal tags (aim 2–3, never more than 5, no generic filler), with the "tags are for finding notes later" reason stated. Nothing else in the prompt changed.

**Decision: `v6` wins — ship it.** It lifts tags on every model (+0.05 to +0.20, mean **+0.125**) *and* raises overall note Quality on every model (+0.019 to +0.037), with no real cost elsewhere. Switch the live prompt from `v5` to `v6`.

## 4. Model summary

Ranking (Quality, on `v6`): **Opus 0.901 > Sonnet 0.887 > Nova Lite 0.866 > Mistral 0.808.**

- **Tags is no longer the universal weak spot** — `v6` pushed Opus (0.886), Sonnet (0.818) and Nova Lite (0.764) above ~0.75. **Mistral (0.689) is the lone remaining sub-0.75** — now the clearest drop candidate.
- Every model improved overall on `v6`; the prompt change helps strong and weak models alike, confirming tags were a wording problem, not a model one.
- **Keep/drop:** keep Opus (ceiling), Sonnet (value pick), Nova Lite (prod baseline) unchanged. **Mistral is now a stronger drop candidate** (weakest Quality + weakest tags even after v6) — actioned as a follow-up MPI, not this run.

## 5. Prompt summary

- **`v6` beats `v5` on Tags for every model** (+0.05 to +0.20; mean 0.664 → 0.789, **+0.125**) and lifts overall Quality for every model (mean 0.838 → 0.866, **+0.028**).
- **No real regression.** The only dips are Sonnet decisions −0.014 and Mistral content −0.030 — both within judge run-to-run noise and outweighed by the tag/quality gains on the same models.
- **Keep `v6`; make it the live prompt** (`PromptCatalog.Current` → `V6`).
- **Next prompt target:** with tags fixed, the lowest remaining sub-scores are **Decisions** (Mistral 0.768) and Content on the weakest model — but these are model-specific, not universal. The bigger lever now is the **model set** (drop/replace Mistral), not another prompt pass.

## 6. Caveats & confidence

- **One 21/22 cell** (`v5` × Nova-Lite, a throttle skip) slightly under-samples that single baseline cell; the v6 win holds comfortably across the other 7 cells and all four models, so the decision is robust.
- **Judge family-bias:** the Anthropic judge ranks the two Claude models top, as before. This does **not** affect the v6-vs-v5 conclusion — that is a within-model before/after on the same judge, and v6 wins on *every* model including the non-Anthropic Mistral.
- **Synthetic only**, single run. The tag gains (+0.05 to +0.20) are far larger than per-run judge variance, so the direction is unambiguous.
