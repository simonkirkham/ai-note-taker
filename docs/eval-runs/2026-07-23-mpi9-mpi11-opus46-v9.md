# 2026-07-23 — MPI-11 (Opus 4.6) + MPI-9 (`analysis@v9`)

**Decision: ship both — prod analysis model `amazon.nova-lite-v1:0` → `anthropic.claude-opus-4-6-v1`, and `PromptCatalog.Current` → V9.** Deploys #707 (model) + #708 (prompt). This is the resolution of the 2026-07-23 manual-vs-generated corpus review ("make the auto notes capture more like mine").

## The question and the answer

The generated notes read as neutral third-party minutes; the user writes dense, subject-first factual bullets. Measured against the [MPI-10 style dimension](2026-07-23-mpi10-style-baseline.md) on the user's own 4 notes, **with the note passed as input (real prod conditions)**:

**Model ladder — current prompt `analysis@v8`:**

| Model | Style | Quality | Actions | Faithfulness | Invocable? |
| --- | --- | --- | --- | --- | --- |
| `amazon.nova-lite-v1:0` (prod before) | 0.30 | 0.375 | 0.35 | 1.00 | ✅ |
| `anthropic.claude-sonnet-4-6` | 0.50 | 0.700 | 0.725 | 1.00 | ✅ |
| **`anthropic.claude-opus-4-6-v1`** | **0.75** | **0.838** | 0.90 | 1.00 | ✅ |

**The style win is model-gated, not prompt-gated.** `analysis@v9` on the weak model (Nova Lite) barely moved style (0.225→0.275) and *regressed* actions; on a capable model it isn't needed to get the style and adds only a little. Swapping Nova Lite → Opus 4.6 on the *unchanged* prompt is the big jump (style 0.30 → 0.75).

**v9 vs v8 on the shipped model (Opus 4.6, same 4 notes):**

| Prompt | Quality | Style | Actions | Decisions | Faithfulness |
| --- | --- | --- | --- | --- | --- |
| **v9** | **0.863** | **0.775** | 0.800 | 0.900 | 1.000 |
| v8 | 0.788 | 0.625 | 0.700 | 0.800 | 1.000 |
| Δ | +0.075 | **+0.15** | **+0.10** | **+0.10** | 0.00 |

On Opus 4.6, v9 is a clean win on every dimension it targets, faithfulness held at 1.0. The **Nova-Lite actions regression did not reproduce** — it was weak-model-specific. So both ship together: the model does the heavy lifting, v9 adds a real style layer on top.

## Frontier access finding

The true frontier — **Opus 4.7/4.8, Sonnet 5, Fable 5** — is **listed** as Bedrock inference profiles in eu-west-2 but returns `AccessDeniedException: <model> is not available for this account` on invoke. Each newer Anthropic model is a separate AWS-Marketplace product requiring a one-time enabling invoke by a Marketplace-permissioned principal (the deploy user isn't one). Opus 4.6 / Sonnet 4.6 were enabled earlier (MPI-3). **Opus 4.6 is the invocable ceiling** for this account today.

To go higher: a human enables the model in the Bedrock *Model catalog → Playground* (the *Model access* page is retired; enablement is now first-invoke + Marketplace subscription), **or** test off-Bedrock with a first-party Anthropic API key. Note: a **Claude Max** subscription is chat/Claude-Code only — it grants no Developer-Platform API access.

## `analysis@v9` — what shipped

Prompt-string rewrite (both `/ai` and no-instruction branches), no output-shape change:
- Subject-first factual bullets; bans "The team discussed X" / "The meeting" / "There is a need to".
- "Longer but terser" density; current-state-first; headers + nested bullets.
- Named attribution; never emit "Speaker N" (use "unknown").
- Reactions-not-judgement (observable reactions, no editorialising).
- Decisions must *close an option* (else empty) + no duplicate bullets.
- The user's note is the **spelling authority** (note wins over transcript).
- Grounding clamp, proper-noun tags, and the `/ai` instructionResponses path carried forward from v8 verbatim (the clamp's "depth" pointer updated to "density").

**Deferred (NOT in v9):** `openQuestions`/`notableQuotes` output fields, a learned per-workspace spelling vocabulary, and the speaker-naming data half (calendar attendees into the analysis input). All remain future work under MPI-9's original scope.

## Cost & operability

- Opus-tier pricing ~80–100× Nova Lite per token; single-user, few-notes-a-day → cents/day.
- Deploy-time neutral (env-var + IAM scope; no new resource, no bake window).
- Model id is a single source of truth in CDK — future model swaps are a one-line default change (env var + IAM grant re-derive together).

## Caveats

- n=4 real fixtures; LLM-judge scores carry ±~0.1 run-to-run noise (a mid-run read of a *shared* results dir also produced a contaminated report during this investigation — eval runs must be serialised; they share `tests/Analysis.Eval/bin/Debug/net10.0/Results`). The **rankings** (Nova Lite ≪ Sonnet 4.6 < Opus 4.6; v9 > v8 on Opus 4.6) are outside the noise; treat individual cell values as approximate.
- Real fixtures are the user's actual meetings — **local-only, git-ignored** (`eval-fixtures-real/`), never committed.
