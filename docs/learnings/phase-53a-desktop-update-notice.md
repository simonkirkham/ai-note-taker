# Learnings: 53-A — desktop update notice

- **A rolling release needs its history keyed by commit, not by build.** Re-publishing the same commit (a re-run, a manual publish) with a fresh build time would have made every copy of that commit count itself one update behind, and the update script — which skips an already-installed commit — could never clear it. Review caught it; no test ran the workflow. **Action:** the history keeps a commit's first entry; spec in `desktop/tests/appendHistory.spec.ts` — Done.
- **`concurrency` with `cancel-in-progress: false` still cancels.** GitHub keeps one pending run per group and cancels the one it replaces, so a queued web-change publish can be dropped for a backend-only one whose own-commit change check then skips the build. Same family as the TI-80 minor-log entry (a workflow-level key eating the run that mattered). **Action:** no group on `publish-desktop.yml`, a spec forbids one, and the older failed-deploy route to the same outcome is filed as [TI-101](../technical-improvements.md#ti-101-the-desktop-installer-skips-a-web-change-whose-own-release-did-not-publish) — Done.
- **A page that renders user content must not choose what goes on the clipboard when the text is meant for a shell.** The first cut let the page pass any string to a main-process clipboard write. **Action:** the shell owns the command (`desktop/src/updateCommand.ts`), the call takes no argument, a spec keeps the displayed copy identical — Done.
- **Anything run by pasting must not assume tools the user may lack.** `update.ps1` needed a signed-in GitHub CLI, and failed with a misleading "no installer found" without it. **Action:** it reads the public release anonymously; the lookup and download were run in real PowerShell 5.1, and the pasted command's "run only if downloaded" guard was watched taking both branches — Done.
- **The orchestrating session's own wait loop matched its own command line** (`pgrep -f` inside a tool call) and hung for 5 minutes. CLAUDE.md already forbids this. **Action:** none new — waits in this slice afterwards used sentinel lines in a log file — Done.
